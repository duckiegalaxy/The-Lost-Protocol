ℹ️ Cloud Backend Setup Details (Supabase Free-Tier)

The Lost Protocol uses Supabase (free-tier PostgreSQL + Auth with Row Level Security). No credit card or billing activation is required.

  1. Create a free Supabase project at supabase.com.
  2. In Supabase Dashboard, run the SQL script in supabase-schema.sql inside the SQL Editor.
  3. Paste your Project URL and public Anon Key in config.js.

When not configured, the game operates seamlessly in local offline mode.
